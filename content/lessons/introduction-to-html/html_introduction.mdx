<Step submit="Continue">

HTML uses tags to define elements. Let's look at a simple example:

<CodeBlock code={"<p>This is a paragraph.</p>"} language="HTML" />

In this example, <CodeHighlight>&lt;p&gt;</CodeHighlight> is the opening tag,
and <CodeHighlight>&lt;/p&gt;</CodeHighlight> is the closing tag. The content
is between these tags.
