<Step submit="Continue">

Text is only half the web. Audio, video, and images bring pages to life — and
each has its own HTML element with built-in browser controls.

</Step>

<Step submit="Continue">

The <CodeHighlight>{"<audio>"}</CodeHighlight> element plays sound. List one or more
<CodeHighlight>{"<source>"}</CodeHighlight> files so the browser can pick a format
it supports.

<CodeBlock code={'<audio controls>\n  <source src="/audio.mp3" type="audio/mpeg">\n</audio>'} language="HTML" />

<Browser content={`<audio controls><source src="/audio.mp3" type="audio/mpeg"></audio>`} title="Audio Element" />

</Step>

<Step submit="Continue">

<Step submit="Continue">

The <CodeHighlight>{"<video>"}</CodeHighlight> element works the same way for moving
pictures, plus sizing attributes and subtitle tracks.

<CodeBlock code={'<video controls width="320" height="240">\n  <source src="/video.mp4" type="video/mp4">\n</video>'} language="HTML" />

<Browser content={`<video controls width="320"><source src="/video.mp4" type="video/mp4"></video>`} title="Video Element" />

</Step>

<Step submit="Continue">

Multiple <CodeHighlight>{"<source>"}</CodeHighlight> tags let you ship several
formats, and a <CodeHighlight>{"<track>"}</CodeHighlight> tag adds subtitles for
accessibility.

<CodeBlock code={'<video controls>\n  <source src="/video.mp4" type="video/mp4">\n  <track src="/subs.vtt" kind="subtitles">\n</video>'} language="HTML" />

<Browser content={`<video controls><source src="/video.mp4" type="video/mp4"></video>`} title="Video with Subtitles" />

</Step>

<Step submit="Finish">

You can now embed audio and video with fallbacks and subtitles. Media makes
lessons memorable — use it with care for every learner's bandwidth.

</Step>
